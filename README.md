# 📊 Unemployment Analysis with Python

## 🚀 Overview
This project analyzes unemployment trends in India, with a focus on the impact of COVID-19.  
It uses data visualization and exploratory data analysis (EDA) techniques to uncover insights.

---

## 📁 Dataset
- Source: CMIE dataset
- Features:
  - Region
  - Date
  - Unemployment Rate
  - Employment
  - Labour Participation Rate
  - Area (Urban/Rural)

---

## 🛠️ Tech Stack
- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly

---

## 📊 Key Insights
- 📈 Spike in unemployment during COVID-19 lockdown (2020)
- 🌍 Regional disparities in unemployment rates
- 🏙️ Urban areas show higher fluctuations than rural areas
